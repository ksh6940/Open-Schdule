OpenLab CLI v1.0 & 일자별 JSON + SQLite 동기화

일반 터미널에서 openlab start -s로 Claude Code 스타일 CLI를 실행하거나, openlab start -s program으로 본 Electron GUI 앱을 실행할 수 있습니다. 모든 일정은 SQLite(todos.db)와 schedules/{date}_schedule.json에 양방향 실시간 저장됩니다.

1. 실행 명령어 (CLI 셸 vs Electron GUI 프로그램)
openlab start -s
openlab start -s program
2. 새 일정 추가 (날짜별 {date}_schedule.json 자동 생성 및 갱신)
openlab start -s add "팀 주간 회의" --date tomorrow --time 14:00 --category 업무 --memo "분기 목표 점검"
openschedule add "저녁 유산소 운동" -d 오늘 -t "19:00" -c 건강
3. 일정 조회 / 상태 변경 / 수정 / 삭제
openlab start -s list --filter today
openlab start -s done 1
openlab start -s edit 1 --title "수정된 제목" --date 2026-11-12
openlab start -s delete 1
