    앱 프로세스의 메모리 사용량과 데이터 관리 기능을 확인합니다.

    Electron 메모리 사용량현재 실행 중인 Electron 프로세스 합계이며 Rust 엔진은 제외됩니다. 측정 전
    HTTP 캐시 비우기임시 웹 캐시만 삭제합니다. 실행 중인 프로세스나 저장된 일정은 유지됩니다.

    데이터 설정

    설정을 초기화하고 일정 데이터와 명령줄 사용법을 확인합니다.

    일정은 SQLite와 schedules/{date}_schedule.json에 동기화됩니다.

    설정 초기화오버레이 설정을 포함한 앱 설정을 기본값으로 복원합니다. 일정은 유지됩니다.
    일정 및 데이터 초기화앱과 엔진을 모두 종료한 후 아래 명령을 실행하세요. 일정, 목록, 일정 JSON 및 설정이 영구 삭제됩니다. 
    openlab delete --data

    명령은 삭제 대상을 표시하고 확인을 요청합니다. 외부에 보관한 별도 백업은 삭제하지 않습니다.

    CLI 셸 / GUI 실행
    openlab start -s
openlab start -s program
